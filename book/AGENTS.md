# Book rules

- Apply the root working rules.
- Teach mathematics, fluid dynamics, and operator learning.
- Keep the theory useful without this repository.
- Do not assume a chosen architecture, dataset, package, or implementation plan.
- Use standalone examples. Put experiment details in project documents.
- Define terms and symbols before use.
- Build each explanation from material already introduced.
- Give assumptions, units, domains, and conventions.
- Use concise prose. Prefer definitions, reasoning, and worked examples.
- Cross-reference shared theory. Do not repeat it.
- Cite primary sources with keys from `references.bib`.
- Check citation metadata and rendered references.
- Use ASCII prose and LaTeX mathematics.
- Check equations with a derivation or a simple example.
- Render changed chapters. Check equations, links, and cross-references.
