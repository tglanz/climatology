# Pandoc Example

Generate the PDF with:

```bash
pandoc index.md \
  --filter pandoc-crossref \
  --pdf-engine=xelatex \
  -o index.pdf
```

This example demonstrates:

* Headings and table of contents
* Text formatting
* Lists
* Tables
* Code blocks
* Images
* LaTeX math
* Numbered equations
* Equation references
* Figure references
* Footnotes
