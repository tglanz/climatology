# Notations

| notation | meaning |
|-|---|
| $t_s$ | spinup time; the timestep at which the simulation leaves its initial transient state |
| $t_c$ | convergence time; the timestep at which the step diagnostic has converged to its long-run climatology |
| $K$ | number of vorticity snapshots in one input window |
| $H$ | number of latitude grid points |
| $W$ | number of longitude grid points |
| $\zeta$ | relative vorticity |
| $\bar{\zeta}$ | time-mean vorticity |
| $[\bar{\zeta}]$ | time-mean zonal-mean vorticity |
| $[\bar{u}]$ | time-mean zonal-mean zonal wind speed|
| $\epsilon_\text{rel}$ | latitude-weighted relative L2 error (relL2); see [docs/norms.md](norms.md) |
